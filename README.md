## Лабораторная работа № 3

**Цель:** изучение основ JavaScript.

**Задание:** написать набор функций на JavaScript и загрузить проект в репозиторий. Задания находятся в файле `lab3/src/core.js`

### Структура проекта

Проект находится в папке `lab3`:

- `src/core.js` - файл с решениями;
- `src/core.spec.js` - тесты;
- `package.json` - описание проекта и зависимостей;
- `README.md`, `.prettierrc`, `.prettierignore`, `.gitignore` - служебные файлы.

### Что реализовано

В файле `core.js` написаны функции:

- `isInteger(n)` - проверка, что число целое, через побитовый оператор `|`;
- `even()` - массив чётных чисел от 2 до 20;
- `sumTo(n)` - сумма чисел от 1 до `n` циклом;
- `recSumTo(n)` - сумма чисел от 1 до `n` рекурсией;
- `factorial(n)` - факториал числа;
- `isBinary(n)` - проверка, что число является степенью двойки, через побитовый оператор `&`;
- `fibonacci(n)` - `n`-е число Фибоначчи;
- `getOperationFn(initialValue, operatorFn)` - замыкание, которое хранит значение и применяет к нему операцию;
- `sequence(start, step)` - генератор арифметической последовательности (по умолчанию начало 0 и шаг 1);
- `deepEqual(a, b)` - глубокое сравнение значений и объектов.

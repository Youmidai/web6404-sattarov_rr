**Цель:** изучение основ HTML и CSS.

**Задание:** разработать многостраничный web-сайт на произвольную тему с использованием HTML и CSS.

**Тема сайта:** чайная «Rocuhodu».

### Структура проекта

Проект находится в папке `lab2`:

- `index.html` - главная страница;
- `catalog.html` - каталог чая (таблица);
- `brewing.html` - способы заварки;
- `contacts.html` - контакты;
- `style.css` - файл стилей, подключается ко всем страницам;
- `images/teapot.svg` - картинка для главной страницы.

### Что реализовано

**HTML**

- 4 страницы, связанные между собой ссылками в меню;
- блочные элементы (`div`, `h1`, `h2`, `p`, `table`, `footer`) и строчные (`a`, `b`, `img`);
- ссылки на другие страницы и ссылка `mailto`;
- картинка на главной странице;
- таблица с каталогом на странице `catalog.html`.

**CSS**

- стили в отдельном файле `style.css`;
- селекторы тега (`body`, `h1`, `a`), класса (`.container`, `.note`), по id (`#header`) и контекстный (`#header a`);
- использован цвет для текста и фона;
- в таблице используется выравнивание по левому краю, по центру и по правому краю.

### Что реализовано

В файле `core.js` написаны функции:

- `isInteger(n)` - проверка, что число целое, через побитовый оператор `|`;
- `even()` - массив чётных чисел от 2 до 20;
- `sumTo(n)` - сумма чисел от 1 до `n` циклом;
- `recSumTo(n)` - сумма чисел от 1 до `n` рекурсией;
- `factorial(n)` - факториал числа;
- `isBinary(n)` - проверка, что число является степенью двойки, через побитовый оператор `&`;
- `fibonacci(n)` - `n`-е число Фибоначчи;
- `getOperationFn(initialValue, operatorFn)` - замыкание, которое хранит значение и применяет к нему операцию;
- `sequence(start, step)` - генератор арифметической последовательности (по умолчанию начало 0 и шаг 1);
- `deepEqual(a, b)` - глубокое сравнение значений и объектов.
